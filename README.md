# H2S AR Quick Look

Unofficial dimension-accurate block models of the Bambu Lab H2S (and H2S Combo with AMS 2 Pro) for placing on a workbench in Apple AR Quick Look.

Not affiliated with Bambu Lab. There is no official Bambu AR model.
